תיקון טעינת יצירות לנגן NEW

1. גבה את app.js ואת index.html הנוכחיים באתר.
2. החלף את app.js בקובץ המצורף. שאר קובצי הנגן נשארים ללא שינוי.
3. העתק update_works_index.py לתיקייה הראשית של הנגן (לצד app.js).
4. ודא שכל קובצי JSON של היצירות נמצאים בתיקייה data.
5. הרץ מתוך תיקיית הנגן: python update_works_index.py
   זה ייצור/יעדכן data/works.json על סמך קובצי היצירות שבפועל.
6. בצע PUSH ל-app.js וגם ל-data/works.json. בצע רענון חזק Ctrl+F5.

שים לב: חבילה זו אינה כוללת תיקיית data ואינה דורסת את נתוני היצירות.

תיקונים:
- כתובת ?data=שם-יצירה תטען את היצירה לפי שם הקובץ (כולל שמות בעברית).
- גם ?data=שם-יצירה.json נתמך.
- אינדקס היצירות יכלול קבצים בעברית.
- בחירה מהרשימה תעדכן גם את פרמטר data בכתובת.
- שימוש ללא data ימשיך להשתמש ב-choir-example כברירת המחדל.
- קוד זמן הסיום לפי end נשאר כפי שהיה בגרסה הקודמת.
