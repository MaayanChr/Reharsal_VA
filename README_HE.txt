נגן NEW – בחירת יצירה וזמן סיום

הבסיס: NEW.zip המקורי. הקבצים app.js, index.html, style.css הורחבו; הפונקציות הקיימות נשמרו.

התקנה באתר קיים:
1. גבו את app.js, index.html, style.css הנוכחיים.
2. החליפו רק את שלושת הקבצים האלה מתוך ZIP זה.
3. העתיקו update_works_index.py לתיקייה הראשית של הנגן.
4. בתיקיית data/ צריכים להיות קובצי ה-JSON של היצירות. אל תמחקו אותם ואל תחליפו אותם בקובץ הדוגמה.
5. מתוך תיקיית הנגן, הריצו: python update_works_index.py
   הפעולה יוצרת או מעדכנת data/works.json לפי כל קובצי היצירות הקיימים.
6. בצעו PUSH כרגיל, כולל data/works.json, לאחר יצירתו.

חשוב: ה-ZIP מכיל תיקיית data עם קובץ דוגמה בלבד. אין להעתיק אותה מעל data/ הקיימת!
אם רוצים להעלות רק שינויים, החליפו שלושה קובצי UI ואת קובץ works.json שנוצר במקום.

רשימת "בחר יצירה":
- כל JSON בעל libraryTitle ו-segments בתיקייה data מופיע ברשימה לאחר יצירת אינדקס.
- החלפת יצירה מחליפה כותרת, קבוצות וקטעים ומנקה את הנגן הקודם.
- נשמרת תמיכה בכתובת הישנה: ?data=filename (בלי סיומת .json).
- בהיעדר works.json נטענת היצירה שבכתובת, או choir-example, כבעבר.
- הוספת יצירה חדשה מחייבת הרצה חוזרת של סקריפט האינדקס (ואחריה PUSH).
- שמות הקבצים צריכים להיות באנגלית/ספרות/קו תחתון/מקף; הכותרות יכולות להיות בעברית.

זמן סיום:
- השדה end בקובץ JSON הוא מספר השניות המוחלט מתחילת הסרטון.
- start: 65, end: 150 = נגינה מ-1:05 עד 2:30.
- end: -1 או בלי end כלל = אין זמן סיום מוגדר (תאימות לאחור).
- בהגעה ל-end: עצירה, או המשך/חזרה לפי האפשרויות הקיימות ב-NEW.
- אין שינוי ידני של end מתוך הנגן בגרסה הזאת.

בדיקת תחביר: node --check app.js
