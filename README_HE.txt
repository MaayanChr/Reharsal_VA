עדכון הנגן: אינדקס יצירות אוטומטי + הסתרת הכותרת בטלפון
================================================================
בסיס: גרסת NEW המתוקנת הקודמת. מנגנון end מתוך JSON נשמר.

1. קובצי הנגן
- העתק app.js, index.html, style.css לתיקיית השורש של הנגן.
- העתק update_works_index.py לאותה תיקייה.
- אל תדרוס את תיקיית data הקיימת.

2. יצירת רשימת יצירות אוטומטית בעת פריסה
- בתיקייה .github/workflows מצורף pages-with-works.yml.
- הקובץ מתאים לאתר סטטי שמפורסם ב-GitHub Pages דרך GitHub Actions,
  כאשר תיקיית האתר היא שורש המאגר והענף הראשי הוא main.
- לפני התקנתו יש לבדוק אם כבר קיים workflow שמפרסם את האתר.
  אם כן, האפשרות המועדפת היא לשלב בו את הצעד:

    - name: Generate data/works.json
      run: python3 update_works_index.py

  אחרי actions/checkout ולפני העלאת/בניית קובצי האתר (artifact).
  אין להפעיל שני workflows עצמאיים שמפרסמים אותו אתר במקביל.
- אם אין תהליך פריסה קיים ב-Actions (או מחליפים את הישן בצורה מודעת),
  ניתן להשתמש ב-pages-with-works.yml כ-workflow מלא.
- ב-Settings > Pages יש להגדיר Source: GitHub Actions.
- בתהליך הזה works.json נוצר בזיכרון ה-runner ונכלל באתר שפורסם.
  הוא לא חייב להופיע בתיקיית data של המאגר ב-Git.
- אם ה-workflow הקיים משתמש ב-branch gh-pages או בתיקיית אתר שונה,
  יש להתאים את צעד יצירת האינדקס ואת נתיב הארטיפקט אליו.

3. התנהגות
- כל JSON תקין של יצירה בתיקיית data (עם segments במבנה אובייקט)
  נכנס לרשימת "בחר יצירה"; works.json אינו נספר כיצירה.
- שינוי בחירת יצירה מעדכן את הכותרת בדסקטופ ואת רשימת הקולות.
- בטלפון (עד רוחב 800px) הכותרת מוסתרת, הבורר נשאר מוצג.
- ?data=filename וכן ?data=שם-בעברית.json ממשיכים לעבוד.
- end: N ו-end: -1 ממשיכים לעבוד.

4. בדיקות
- פתח את האתר ללא data: הרשימה אמורה להכיל את כל היצירות.
- פתח עם ?data=שם-קובץ: היצירה אמורה להיטען והיא מופיעה כבחירה.
- פתח בטלפון: הכותרת מוסתרת, אך "בחר יצירה" מוצג.
- בדוק ניגון וידאו, רצף, חזרה, מהירות ו-end.
